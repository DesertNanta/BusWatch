BUSWATCH MULTI-PAGE HTML PROTOTYPE
==================================

Isi paket:
- index.html          : Ringkasan / dashboard utama
- planner.html        : Rencana perjalanan
- tracking.html       : Live tracking bus
- stops.html          : Halte dan koridor
- notifications.html  : Pusat notifikasi
- operator.html       : Dashboard operator
- styles.css          : Gaya bersama untuk semua halaman
- app.js              : Interaksi bersama dan data simulasi

CARA MENJALANKAN
1. Ekstrak semua isi ZIP ke satu folder.
2. Buka index.html dengan browser modern (Chrome, Edge, Firefox).
3. Gunakan navigasi di sisi kiri untuk berpindah halaman. Setiap menu adalah file HTML tersendiri dan tetap terhubung melalui tautan relatif.

CATATAN
- Semua data bus, rute, halte, angka KPI, dan ETA adalah data contoh/simulasi.
- Prototipe belum terhubung ke GPS nyata, API peta, server, atau layanan operator.
- Simpan semua file dalam folder yang sama agar styles.css dan app.js dapat dimuat dengan benar.
