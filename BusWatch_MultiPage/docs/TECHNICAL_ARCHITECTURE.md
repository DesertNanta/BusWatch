## 1. Vision

BusWatch adalah platform informasi dan mobilitas bus terintegrasi yang menghubungkan penumpang dan operator, dengan fondasi yang dapat dikembangkan untuk pemerintah dan berbagai kota di Indonesia.

Target awal: Wilayah Bali (Denpasar dan sekitarnya) | Moda: BRT dan bus kota.

---

## 2. Architecture Decision: Modular Monolith

**Decision:** Gunakan Modular Monolith, bukan Microservices.

**Reasoning:**
- Tim solo developer dengan anggaran nol.
- MVP dalam 1–3 bulan tidak membutuhkan kompleksitas microservices.
- Modular Monolith tetap memungkinkan pemisahan yang bersih antar domain.
- Dapat di-extract menjadi microservices di masa depan jika skala meningkat.

**What this means:**
- Satu aplikasi Next.js (frontend + API).
- Satu database PostgreSQL.
- Pemisahan logika per modul (`src/modules/`), bukan per service.

## 5. Data Flow

```
Browser
  │
  ├── Next.js Page (Server Component)
  │     └── Prisma → PostgreSQL/PostGIS
  │
  ├── Next.js Page (Client Component via dynamic import)
  │     └── Leaflet map (window/document required)
  │
  └── API Route (/api/*)
        └── Prisma → PostgreSQL/PostGIS
```

## 6. Multi-City & Multi-Operator Architecture

```
City ──< CityOperator >── Operator
  │                           │
  ├── Corridor                ├── Vehicle
  │     └── Route                   └── GpsDevice
  │           └── RouteStop               └── GpsPosition
  └── Stop
```

**Isolation rules (enforced at service layer):**
- An operator can only read/write data under their `operatorId`.
- Foreign keys enforce referential integrity.
- Row-level security (future) will add DB-level isolation.

---

## 7. GPS Architecture

```
Physical Device / Simulator
        │  POST GPS coordinates
        ▼
  API Route: /api/gps/ingest (future)
        │
        ├─→ gps_positions (append-only history)
        │
        └─→ vehicle_current_positions (upsert — only if timestamp is newer)
```

**Key rule:** Only update `vehicle_current_positions` if `incoming.timestamp > existing.last_timestamp`. This prevents out-of-order packets from overwriting fresher data.

## 8. Leaflet / SSR Strategy

Leaflet cannot run server-side because it accesses `window` and `document`.

**Solution used:** `next/dynamic` with `ssr: false`.

```tsx
const BuswatchMap = dynamic(() => import("@/components/map/BuswatchMap"), {
  ssr: false,
  loading: () => <div>Memuat peta…</div>,
});
```

The `BuswatchMap.tsx` component is marked `"use client"` and uses `useEffect` to initialize Leaflet only after the browser DOM is ready.
